# 四六级作文：模板怎么用才不被扣分

很多人准备作文时，先收藏一篇“万能范文”，再把题目里的词替换进去。真正危险的不是用了常见句式，而是全文看似流畅，却没有完成题目交代的任务。模板应该帮你组织内容，不能替你判断写什么。本文给出一套能直接练习的方法，不提供所谓押题和保分承诺。

## 一、先弄清楚：模板不是评分依据

中国教育考试网公布的笔试结构中，四级、六级写作时间均为30分钟。官方考试大纲强调中心思想、篇章组织、词汇、语法和连贯表达；大纲中的最低词数要求分别为四级120词、六级150词。实际作答仍应逐字看清当次试卷的词数和任务要求，不要只记一个数字。

没有必要把“出现某句常见表达”直接理解为必然扣分，也不能相信“背完这套模板就能拿高分”。准备句式的目的，是减少临场造句的负担，把注意力留给审题和展开论证。一个简单、准确且贴题的句子，通常比意思含混的复杂句更值得保留。

## 二、动笔前，用四个问题拆开任务

拿到题目后，先在心里回答：

1. 我在以什么身份写？学生、志愿者，还是活动组织者？
2. 写给谁？面向同学的建议，和写给老师的邮件，语气不同。
3. 必须完成什么？解释原因、比较选择、介绍活动，还是提出建议？
4. 有没有指定开头、材料信息或格式？有就优先遵守，不能自行另起炉灶。

例如，题目要求给新生介绍图书馆，正文就应交代用途、使用方法或建议。即使背得很熟，也不该大篇幅讨论“随着社会发展，读书越来越重要”。把任务写成一句中文，再列两三条必须包含的信息，往往比马上写华丽开头更有效。

## 三、只背骨架，不背整篇

可以准备三类骨架，但它们不是强制段落数。

- **观点讨论**：明确观点—给出理由并解释—补充边界或行动建议。
- **问题建议**：说明具体问题—提出可执行办法—解释办法为什么有用。
- **应用文**：说明来意—交代必要信息—提出请求或表达期待。

每个骨架只保存自己真正会用的短句。例如，提出建议时可写“We can start by setting a clear goal.”，接着必须说明是什么目标、如何执行。不要把一句通用表达扩写成半段空话。

更实用的笔记是“表达功能表”：提出原因、举例、对比、总结各留两三种写法，并为每个句式写一个自己的例句。确认介词、单复数和动词形式后再记忆，不收藏自己都解释不清的长句。

## 四、让每个理由都落到具体动作

假设练习题是“大学生如何合理使用手机”，下面的内容就有明显区别：

空泛写法：“合理使用手机很重要，它对我们的生活有很大影响。”

具体写法：“复习时把手机放进书包，并在完成一组练习后集中查看消息，可以减少被通知打断的次数。”

写英语时，不必逐字翻译这句中文。可拆成两三个自己有把握的短句：先写做法，再写结果。一个段落围绕一个理由，形成“观点—解释—例子或结果”的链条。例子可以是明确标注的假设场景，不必编造调查比例、名人名言或自己的亲身经历。

六级备考还可以练习补充条件：手机并非只能带来干扰，查词和查找学习信息也有用，关键在于用途与边界。这样的限定比重复同一个观点更能推进讨论，但也不能脱离题目随意发挥。

## 五、把30分钟拆成三步练

下面是训练分配，不是官方规定：

- 前4分钟：审题，确定身份、对象和任务，列出每段要点。
- 中间22分钟：完成全文。想不起高级词时，用准确的普通词替代；不要在一句话上停太久。
- 最后4分钟：检查是否遗漏任务，再看语法、拼写和格式。

检查顺序也要有轻重。先处理跑题、漏写内容和句子不完整，再检查主谓一致、名词单复数、时态、冠词及标点。不要为了把同一个词换成“高级同义词”，临场改成不熟悉的搭配。字迹应清楚，修改尽量简洁，具体作答位置和要求听从试卷及监考指引。

## 六、用三篇练习，判断模板是否真的会用

第一篇，不看范文，只用骨架限时写完。第二篇，保留相同的表达功能，换成不同话题，观察哪些句子必须跟着任务变化。第三篇，换一种文体，检验自己是否还在机械套用议论文。

每次复盘只记三件事：遗漏了什么要求、哪句话表达不清、下次能直接替换成什么正确表达。隔一天不看原稿再写一遍。能在新题里独立使用，才算掌握；只会默写原文，不算迁移。
