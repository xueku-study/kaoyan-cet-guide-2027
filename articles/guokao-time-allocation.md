# 国考行测：考场时间怎么分配

行测练习中，有一种令人沮丧的情况：对答案时发现很多题会做，考试时却根本没有读到。问题不一定是知识不足，也可能是前面几道题花掉了后面整个模块的时间。时间管理不是“越快越好”，而是在限定时间里，把已经具备的能力稳定发挥出来。

## 一、先确认试卷，不照抄别人的顺序

国家林业和草原局转载的2026年度国考公共科目笔试大纲明确：行测为客观性试题，考试时限120分钟，涉及政治理论、常识判断、言语理解与表达、数量关系、判断推理和资料分析等部分。

本文用这一已核实的大纲作为训练背景，不把它当作以后年度永不变化的承诺。参加其他年度考试，应重新核对当年度大纲、职位对应类别、准考证和试卷注意事项。不要把网上流传的单题分值表当作官方评分规则，也不要拿省考或事业单位试卷的节奏直接套国考。

“先做资料分析”不是对所有人都适用。你若读表慢，反而可能开场就陷进去。顺序需要通过完整模拟决定，不能仅凭听起来很有道理的经验。

## 二、先测三次，再给每个模块定预算

选择合法取得、类别相符且没有做过的练习卷，完整计时。至少记录三次，每次保留四项信息：模块用时、完成题数、正确题数、最后没来得及做的题数。复盘可以不限时重做，但不能把重做结果混进限时表现。

看记录时要区分三种情况：

- 用时短、正确表现稳定：适合保留稳定预算，不必盲目继续压缩。
- 用时长、正确表现尚可：检查是否卡在少数题上，优先解决停留过久。
- 用时长、正确表现也不理想：回到专项补基础，不能靠不断加时间解决。

若某模块一套卷发挥很好，另外两套明显波动，不要立刻认定它是优势。先看波动来自知识差异、阅读失误，还是顺序导致的疲劳。

## 三、一份可修改的120分钟预算

下面只是初次模拟的起点，不是官方推荐，也不对应固定题量：

| 项目 | 示例预算 |
| --- | --- |
| 政治理论与常识判断 | 18分钟 |
| 言语理解与表达 | 25分钟 |
| 判断推理 | 30分钟 |
| 资料分析 | 25分钟 |
| 数量关系 | 15分钟 |
| 机动与答题卡核对 | 7分钟 |
| 合计 | 120分钟 |

表格是预算清单，不代表必须按表格顺序作答。每个模块的时间应包含读题、演算和对应填涂；最后的机动时间不是让你把整张答题卡都留到最后填。

假如资料分析稳定需要28分钟，可以从其他模块缩减3分钟，但必须写清楚从哪里减，不能每一项都“多给一点”。每次模拟只调整一个主要变量，例如交换两个模块的顺序，或调整一个模块的预算，才看得出变化是否有效。

## 四、决定跳题的标准，要在考前练过

最需要警惕的信号不是“这道题难”，而是“继续投入却没有新的进展”。阅读一遍仍找不到设问重点、数量题试了一个方向仍无法建立关系、图形题反复看却没有可检验的规律，都可以成为暂时跳过的信号。

不要把“已经花了两分钟”当作必须做完的理由。已经花掉的时间收不回来，继续停留还可能错过后面的基础题。练习时可给容易纠缠的题型设置个人提醒线，超过提醒线便判断是否继续；这不是所有题统一限时，一篇材料带多道题与一道独立题不能机械比较。

跳题时在允许的试卷位置做清楚标记，并保持题号对应。不要在答题卡上作不符合要求的记号。后续若回看，优先处理已经排除部分选项、只差一步即可完成的题，而不是重新挑战最陌生的难题。

## 五、用累计检查点，防止整卷失控

把最终确定的模块顺序写成练习用清单，计算累计预算。例如，前两个模块结束时应大约用了多少分钟，而不是只记“每题要快”。模拟时只在模块转换或预设节点看时间，不必每做一题就看表。

如果发现超时，先判断偏差在哪里。只是个别题拖延，就停止纠缠并切换；如果整类题都比预计慢，应执行提前练过的缩减方案。不要临时把后面一整个擅长模块全部取消，也不要因为刚错过一个检查点就慌乱加速，连题干中的“不正确”都没看见。

最后阶段先确认已作答内容填涂完整、题号无错位，再处理剩余题。任何补答或修改都必须在考试允许的时间内完成，停笔信号后立即遵守要求。

## 六、一次模拟后，真正该改什么

复盘不要只写“下次快一点”。可以记录：“第三组资料因单位没看清重复计算，下次先圈单位”“数量题无思路仍停留太久，下次触发跳题提醒”。每次选两个可执行动作，下一套卷检验。
